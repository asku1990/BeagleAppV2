# Issue tracker: Linear

Linear is the canonical issue tracker for this repo. GitHub is a synchronized mirror and is not edited directly.

## Conventions

- Create issues in Linear using the configured Linear CLI/API integration.
- Read, update, label, and close issues in Linear using the configured Linear CLI/API integration.
- Use the synchronized GitHub issue only as a mirror; do not create or modify GitHub issues directly.

## When a skill says "publish to the issue tracker"

Create the issue in Linear.

## When a skill says "fetch the relevant ticket"

Read the issue from Linear.

## Triage and synchronization

Apply triage labels and state changes in Linear. Allow the Linear/GitHub synchronization to update the GitHub mirror.
